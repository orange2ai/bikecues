# 骑码 bikecues

为骑行而生的 iPhone / Apple Watch 码表与语音播报 App。

Keep 往语音播报里加广告，苹果自带的体能训练能显示实时数据却不能播报，骑码就是为填这个空位而做的。

- 起点极小：骑行时语音播报速度、距离、心率
- 终点清晰：基于 Apple Watch 的原生码表体验，只卖服务，不卖硬件

## 原则

1. **省电** · 骑行是长时间运动。OLED 纯黑即熄灭，骑行页永远 100% 黑底，不需要变暗的花招
2. **原生** · 和苹果系统深度打通，记录按最兼容的方式写入苹果健康（HealthKit），也读取系统已有的记录。不导流，不另建孤岛
3. **数据永不丢失** · 本地优先，健康兜底，iCloud 同步（规划中），Markdown 导出（供人阅读，也供 agent 分析）
4. **无广告，永久** · 不卖货，不打广告，不搞歪门邪道。你买的是软件本身，是设计和用心
5. **开源，仅限自用** · 代码公开，欢迎学习和自建。仅限非商业用途，与本仓库商店发行版互不冲突
6. **买断制** · 一次付费，永久使用，后续功能不另收费

## 为什么叫 bikecues

在骑行和跑步社区，audio cues 是用户讨论"数据播报"时最自然的说法（Strava、Runkeeper 的同名功能），而语音导航叫 voice guidance / turn-by-turn，两者在行业里界限分明。bikecues = bike + cues，名字即功能。中文版叫**骑码**：码表的码，骑马的马。

## 路线

- [ ] MVP：iPhone 端 GPS 记录 + AVSpeechSynthesizer 播报 + HealthKit 写入
- [ ] Apple Watch 伴侣：抬腕即看的码表，蓝牙心率广播链路实时心率
- [ ] 手表独立记录：HKWorkoutSession，不带手机也能骑
- [ ] 数据出口：Markdown 导出、iCloud 同步
- [ ] AI 骑行分析（骑码 Pro）
